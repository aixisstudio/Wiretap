Snap — packet capture under confinement¶

The snap is built by electron-builder (linux.target includes "snap") in strict confinement. Packet capture uses AF_PACKET sockets, which the network-observe interface grants (the same model the tcpdump snap uses). After installing a local .snap:

sudo snap install --dangerous Wiretap-amd64.snap
sudo snap connect wiretap:network-observe   # grants AF_PACKET read access

Without the network-observe connection the UI still runs but capture stays empty. Store publication would auto-connect that interface once human-reviewed; until then the manual connect is required.

rpm + Homebrew formula + release pipeline¶

The release.yml workflow (on every v* tag or workflow_dispatch) runs four publish jobs:

Job Output
nfpm wiretap-linux-amd64.rpm — native build via nfpm v2.48 (packaging/nfpm.yaml + packaging/postinstall.sh)
homebrew pushes Formula/wiretap.rb to aixisstudio/homebrew-tap — installs the headless wiretapd daemon (brew install aixisstudio/tap/wiretap). Requires HOMEBREW_TAP_TOKEN.
winget submits Wiretap-Setup-*.exe via winget-releaser when the asset exists; skips cleanly otherwise. Requires WINGET_TOKEN.
chocolatey choco pack/push of installer/Wiretap.nuspec when CHOCO_API_KEY is set.

Flatpak — deliberately not shipped¶

Flatpak's sandbox cannot grant AF_PACKET access: there is no portal or finish-args combination that exposes raw packet capture, and process attribution via psutil needs host /proc visibility the sandbox denies. Shipping a Flatpak would produce a pretty UI that can never see a packet — we'd rather not publish a broken app than fake it. If flathub ever grows a capture-capable permission, revisit.

Snap — capture de paquets sous confinement¶

Le snap est construit par electron-builder (linux.target inclut "snap") en confinement strict. La capture utilise des sockets AF_PACKET, que l'interface network-observe autorise (le même modèle que le snap tcpdump). Après installation d'un .snap local :

sudo snap install --dangerous Wiretap-amd64.snap
sudo snap connect wiretap:network-observe   # autorise la lecture AF_PACKET

Sans cette connexion, l'UI tourne mais la capture reste vide. Une publication sur le Store connecterait l'interface automatiquement après revue ; en attendant, la connexion manuelle est requise.

Flatpak — volontairement non publié¶

La sandbox Flatpak ne peut pas accorder l'accès AF_PACKET : aucun portal ni combinaison de finish-args n'expose la capture de paquets brute, et l'attribution par processus via psutil exige une visibilité /proc de l'hôte que la sandbox refuse. Publier un Flatpak produirait une jolie UI incapable de voir le moindre paquet — mieux vaut ne pas publier une app cassée que de simuler. À revoir si flathub ajoute une permission de capture.
