主要な不変条件

  • パケットごとのコルーチンやブロードキャストなし — キュー 1 本、ドレイン タスク 1 本、~250 ms ごとの batch WS メッセージ 1 本。
  • remote_port は常に方向を考慮；dst_port は分類に使わない （受信ではローカルポートのため）。
  • 明示的オプトインなしの第三者呼び出しはコード中に存在しない。
  • 検出器は全ての可変状態をロックで保護し、全コンテナはサイズ上限付き。
  • macOS: メディア監視は supported: false を返し、UI はバッジを隠す。

レイヤ概要

  • キャプチャ: pcap.py（ctypes → libpcap/Npcap）＋独自 parser.py （Ethernet、拡張付き IPv4/IPv6、TCP/UDP、DNS 応答、TLS SNI）。
  • パイプライン: 上限付きキュー → 単一ドレインタスク（~4 Hz）→ ティックごとの batch WS メッセージ。
  • 分類: 常に remote_port（方向考慮）。
  • エンリッチ: 観測 DNS/SNI > 逆引き DNS > ローカル .mmdb；タスクは 重複排除、失敗は恒久的にキャッシュしない。
  • セキュリティ: firewall.py が OS ファイアウォール （netsh/iptables/pf）を連携 — 永続ルール、lockdown、ブロックカウンタ； threatintel.py が LRU キャッシュ付きオプトイン評判照会。
  • 永続化: トラフィック集計、アラート、設定を SQLite に；停止時に フラッシュ；保持期間は設定可。
