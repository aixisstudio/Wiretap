Wer unter Windows einen Netzwerkmonitor gesucht hat, stieß auf GlassWire. Es ist poliert, sieht gut aus — und dann tauchen die Paywalls auf: Verlauf hinter Abo, Firewall-Features hinter Tiers, ein Account, der ständig angeboten wird, Cloud-"Elite"-Sync.

Nichts gegen bezahlte Software. Aber "zeig mir, womit mein Computer verbunden ist" ist Basishygiene — sollte wohl kaum gesperrt sein. Ich bin der Autor von Wiretap, einer kostenlosen Open-Source-Alternative (AGPL) — hier also der ehrliche Vergleich statt eines Verkaufsgesprächs.

Wo GlassWire weiterhin gewinnt¶

Fairerweise:

  • Blocking-Reife. GlassWires Application Firewall wurde ein Jahrzehnt verfeinert — Wiretaps Outbound-Blocking (seit v1.2) orchestriert die OS-Firewall best-effort und braucht Capture-Rechte, um Regeln wirklich anzuwenden. Wenn interaktive "App verweigern"-Prompts dein Kernbedarf sind, bleibt GlassWire (oder das kostenlose Portmaster) die poliertere Wahl.
  • Polish. GlassWire hatte ein Jahrzehnt UI-Arbeit. Wiretap ist viel jünger — der Graph ist stark, die Einstellungen funktional, Ecken erwarten.
  • Lange Verlaufs-Aufbewahrung — Wiretap hält 24 h by design (Privacy-first heißt auch, deinen Traffic nicht zu horten).

Der Architektur-Unterschied, der zählt¶

GlassWires Modell ist das der Branche: Free-Tier → Ärgernis → Abo → Cloud-Features. Wiretaps Modell ist das Gegenteil: Das Binary, das du startest, ist das ganze Produkt. Nichts freizuschalten, weil nichts gesperrt ist. Dein Verlauf lebt in einer lokalen SQLite-Datei — und der Code ist AGPL, er kann also nicht heimlich anfangen nach Hause zu telefonieren, ohne dass der Diff öffentlich wäre.

Konkret: API auf Loopback mit Token-Auth, null Telemetrie-Endpoints, kein Analytics-SDK irgendwo im Code (grep es — es ist Open Source).
