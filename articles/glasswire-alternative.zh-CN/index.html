如果你在 Windows 上找过网络监控工具，一定遇见过 GlassWire。它精致漂亮——然后付费墙接踵而至：历史记录要订阅、防火墙功能分档、不断推荐的账号、云端「精英」同步。

为软件付费没有错。但「让我看看电脑在和谁通信」属于基础卫生——本就不该上锁。我是 Wiretap 的作者——一款免费的开源（AGPL）替代品——所以这里给出诚实的对比而非销售话术。

GlassWire 仍然胜出的地方¶

公平地说：

  • 阻断成熟度。 GlassWire 的应用防火墙打磨了十年——Wiretap 的出站阻断（v1.2 新增）以 best-effort 方式编排 OS 原生防火墙，真正应用规则需要抓包级权限。如果交互式「拒绝此应用」是你的核心需求，GlassWire（或免费的 Portmaster）仍是更成熟的选择。
  • 完成度。 GlassWire 有十年的 UI 积累。Wiretap 年轻得多——图很棒，设置够用，边角粗糙请见谅。
  • 长历史保留 —— Wiretap 设计上只保留 24 小时（隐私优先也意味着不囤积你的流量）。

真正重要的架构差异¶

GlassWire 的模式是行业惯例：免费档 → 烦扰 → 订阅 → 云功能。Wiretap 相反：你运行的二进制就是产品全部。没有要解锁的，因为没有上锁的。你的历史存在本地 SQLite 文件里——代码是 AGPL，想偷偷 phone-home，diff 立刻公之于众。

具体来说：API 绑定 loopback 且 token 认证，零遥测端点，代码里没有任何分析 SDK（你可以 grep——它是开源的）。
