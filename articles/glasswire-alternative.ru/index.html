Если вы искали сетевой монитор под Windows, вы натыкались на GlassWire. Он отполирован, красив — а потом начинаются пейволы: история за подпиской, фаервол по тарифам, навязчивый аккаунт, облачная «элитная» синхронизация.

Платить за софт — нормально. Но «покажи, куда коннектится мой компьютер» — это базовая гигиена, которую, пожалуй, вообще не стоит прятать за оплату. Я автор Wiretap — бесплатной open-source альтернативы (AGPL), поэтому вот честное сравнение вместо продающего питча.

Где GlassWire всё ещё выигрывает¶

Честно говоря:

  • Зрелость блокировки. Фаервол приложений GlassWire шлифовался десятилетие — исходящая блокировка Wiretap (добавлена в v1.2) оркестрирует нативный фаервол ОС best-effort и требует привилегий захвата для реального применения правил. Если интерактивные «запретить это приложение» — ваша основная потребность, GlassWire (или бесплатный Portmaster) остаётся более отполированным выбором.
  • Полировка. У GlassWire десятилетие работы над UI. Wiretap гораздо моложе — граф отличный, настройки функциональные, ждите шероховатостей.
  • Долгое хранение истории — Wiretap хранит 24 ч by design (privacy-first значит и не копить ваш трафик).

Архитектурная разница, которая важна¶

Модель GlassWire — отраслевой стандарт: free-тариф → раздражение → подписка → облачные функции. Модель Wiretap — противоположная: бинарь, который вы запускаете, и есть весь продукт. Нечего разблокировать, потому что ничего не заблокировано. Ваша история живёт в локальном файле SQLite — а код под AGPL, так что он не может тихо начать стучать домой без публичного diff'а.

Конкретно: API на loopback с токен-аутентификацией, ноль эндпоинтов телеметрии, ни одного аналитического SDK в коде (можно grep'нуть — это open source).

Попробуй¶

# Windows: установите Npcap, затем запустите release-exe от имени администратора
# Linux/Docker:
docker run --network host ghcr.io/aixisstudio/wiretap
# macOS: упакованное приложение или brew
# Демо-режим без admin: WIRETAP_DEMO=1

Репо: https://github.com/aixisstudio/Wiretap — issues и feature requests приветствуются, сам Windows-порт был сделан сообществом. Если он заменяет подписку, которая вам не нужна — в этом и смысл. ⭐ если так.
