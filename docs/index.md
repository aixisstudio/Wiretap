# Wiretap

**The firewall that knows whether YOU were there when data left. / Le pare-feu qui sait si VOUS étiez là quand les données sont parties.**

## English

Wiretap is an open-source application firewall and real-time network monitor that asks the question no other security tool asks: **were you there when the data left?**

- **[Deep signals](deep-signals.md)** — presence-correlated exfiltration, Flow DNA, kill-chain correlation, tamper-evident forensics, blast radius, time-travel
- **[Firewall & blocking](FIREWALL.md)** — OS-native orchestration, lockdown, canaries, honeyports, auto-response
- **[Architecture](architecture.md)** — how the capture pipeline works
- **[Integrations](INTEGRATIONS.md)** — SIEM, fleet, syslog, ECS exports
- **[Comparison](COMPARISON.md)** — honest Wiretap vs Little Snitch vs GlassWire vs Portmaster
- **[Threat model](threat-model.md)** — what Wiretap does and does not defend against

**Download**: [github.com/aixisstudio/Wiretap/releases](https://github.com/aixisstudio/Wiretap/releases) — macOS, Windows, Linux. 100% local-first, no account, no telemetry.
