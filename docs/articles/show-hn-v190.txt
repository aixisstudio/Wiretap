Show HN: Wiretap – the firewall that knows whether you were there when your data left

Every security tool asks "what is leaving this machine?" None ask "was a human present when it left?"

Wiretap is a local-first, open-source network security monitor for macOS/Windows/Linux. v1.9.0 ships four rounds of signals built on that question:

- Presence-correlated exfiltration: reads OS input-idle time (zero privileges) and grades every sensitive outbound flow. 5MB to an AI API while you type is you; the same 5MB while your machine sat idle is something else acting in your name.
- Flow DNA: per-process traffic metabolism (burst sizes, rhythm, direction ratio, destination entropy) with drift detection. A compromised binary keeps its name but changes its metabolism.
- Persistence surface watch: diffs every auto-start mechanism (LaunchAgents, Run keys, systemd, cron) over time. Malware must persist to survive reboot; nobody in this category watches the surface.
- Blast radius: when a critical alert fires, the worst-case impact assessment ("talked to 3 destinations; reached Anthropic; survives reboot; held 21 files open") is computed in milliseconds and attached to the alert itself.
- Time-travel: "what changed on this machine since Tuesday?" answered by diffing hourly state snapshots.

Underneath: kill-chain correlation across 14 detector families (3 distinct families on one entity = composite incident), automatic lockdown response (opt-in), and a hash-chained forensic alert log where deleting evidence breaks the chain and becomes itself proof.

AI-era coverage: traffic governance across 21 AI providers (shadow-AI detection, upload spikes), MCP server risk audits, secrets egress watch, supply-chain install correlation. Metadata only, nothing leaves the machine.

Local-first, no account, no cloud. Python backend + React/Electron UI. 414 tests. PolyForm Shield license.
