Windows でネットワークモニターを探したことがあれば、GlassWire にぶつかったはず。洗練されていて見た目も良い — そして paywall が始まる: 履歴はサブスク、ファイアウォール機能はティア制、しつこく提示されるアカウント、クラウド「エリート」同期。

ソフトに金を払うこと自体は悪くない。だが「自分の PC が何に繋がっているか見せて」は基本的な衛生 — 課金ゲートすべきではないとも言える。私は Wiretap の作者 — 無料のオープンソース（AGPL）代替 — なので、セールストークではなく正直な比較をする。

GlassWire がまだ勝る点¶

公平に言うと:

  • ブロッキングの成熟度。 GlassWire のアプリケーションファイアウォールは 10 年の洗練がある — Wiretap の送信ブロッキング（v1.2 追加）は OS ネイティブファイアウォールを best-effort で連携し、実際のルール適用にはキャプチャ権限が必要。インタラクティブな「このアプリを拒否」プロンプトが本筋なら、GlassWire（または無料の Portmaster）が依然として洗練された選択。
  • 完成度。 GlassWire は 10 年の UI 開発がある。Wiretap はずっと若い — グラフは素晴らしいが、設定は実用レベル、粗さは覚悟を。
  • 長期履歴保持 — Wiretap は設計上 24 時間のみ（プライバシーファーストとはトラフィックを溜め込まないことでもある）。

重要なアーキテクチャの違い¶

GlassWire のモデルは業界標準: 無料ティア → 苛立ち → サブスク → クラウド機能。Wiretap は逆: 実行するバイナリが製品の全部。ロックが無いから解除も無い。履歴はローカル SQLite ファイルに住む — コードは AGPL なので、こっそり phone-home し始めれば diff が公開される。

具体的に: API は loopback でトークン認証、テレメトリエンドポイントゼロ、コード内に分析 SDK は一切無い（grep してみて — オープンソースだから）。

試してみる¶

# Windows: Npcap をインストール、release の exe を管理者として実行
# Linux/Docker:
docker run --network host ghcr.io/aixisstudio/wiretap
# macOS: パッケージ版アプリまたは brew
# 管理者無しのデモモード: WIRETAP_DEMO=1

Repo: https://github.com/aixisstudio/Wiretap — issue と feature request 歓迎、Windows 移植自体がコミュニティ貢献。要らないサブスクを置き換えられたなら、それが狙い。⭐ その場合はぜひ。
