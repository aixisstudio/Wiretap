If you've searched for a network monitor on Windows, you've hit GlassWire. It's polished, it looks great — and then the paywalls start showing up: history behind a subscription, firewall features behind tiers, an account that keeps being suggested, cloud "elite" sync.

There's nothing wrong with paying for software. But "show me what my computer connects to" is basic hygiene — it arguably shouldn't be gated at all. I'm the author of Wiretap, a free, open-source (AGPL) alternative, so let me give you the honest comparison instead of a sales pitch.

Where GlassWire still wins¶

Being fair:

  • Blocking maturity. GlassWire's application firewall has had a decade of refinement — Wiretap's outbound blocking (added in v1.2) orchestrates the OS-native firewall best-effort and needs capture privileges to actually apply rules. If interactive "deny this app" prompts are your core need, GlassWire (or free Portmaster) is still the more polished choice.
  • Polish. GlassWire's had a decade of UI work. Wiretap is much younger — the graph is great, the settings are functional, expect edges.
  • Long history retention — Wiretap keeps 24h by design (privacy-first means not hoarding your traffic either).

The architecture difference that matters¶

GlassWire's model is the industry's: free tier → annoyance → subscription → cloud features. Wiretap's model is the opposite: the binary you run is the whole product. Nothing to unlock because nothing is locked. Your traffic history lives in a local SQLite file — and the code is AGPL, so it can't quietly start phoning home without the diff being public.

Concretely: API on loopback with token auth, zero telemetry endpoints, no analytics SDK anywhere in the code (you can grep it — it's open source).

Try it¶

# Windows: install Npcap, then run the release exe as Administrator
# Linux/Docker:
docker run --network host ghcr.io/aixisstudio/Wiretap
# macOS: packaged app or brew
# Demo mode without admin: WIRETAP_DEMO=1

Repo: https://github.com/aixisstudio/Wiretap — issues and feature requests welcome, the Windows port itself was community-contributed. If it replaces a subscription you didn't want, that's the point. ⭐ if it does.
