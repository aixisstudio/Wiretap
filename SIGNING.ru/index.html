Текущее состояние¶

Сборки Wiretap не подписаны под Windows и macOS. Это честно и осознанно: мы не будем выпускать самоподписанные сертификаты, обесценивающие саму подпись, и не будем покупать сертификат, пока для open source существует легальный бесплатный путь.

Windows — SignPath Foundation (бесплатно для OSS)¶

SignPath предлагает бесплатную подпись Authenticode подходящим open-source проектам. Одобренные проекты получают политику release-signing, дающую публично доверенные подписи — SmartScreen перестаёт предупреждать по мере накопления репутации.

Настройка (одноразово, только мейнтейнер)¶

  1. Подать заявку на https://signpath.org/apply — форма с именем, email, проектом, URL репозитория и описанием. Одобрение ручное (дни). Wiretap соответствует всем опубликованным условиям: AGPL-3.0 (одобрена OSI, без двойного лицензирования), полностью открытый код, активно поддерживается, уже выпускается на GitHub Releases, документирован. Заявка подана — на рассмотрении.
  2. Создать организацию SignPath, проект (slug, напр. Wiretap), привязать доверенную build-систему GitHub.com и установить GitHub App SignPath на этот репозиторий (нужна для проверки источника).
  3. Создать политику release-signing, ограниченную сборками по тегам, с конфигурацией артефактов *.exe в ZIP (стандартный шаблон подходит).
  4. В GitHub → Settings → Secrets and variables → Actions:
  5. Переменные: SIGNPATH_ORGANIZATION_ID, SIGNPATH_PROJECT_SLUG, SIGNPATH_POLICY_SLUG
  6. Секрет: SIGNPATH_API_TOKEN
  7. Готово — CI-джоб SignPath — submit signing request активируется сам при следующем теге: загружает неподписанный инсталлятор, ждёт подписанную копию и заменяет артефакт до загрузки в release. Всё инертно до шага 4.

macOS — бесплатного пути нет¶

Apple требует платное членство Developer Program ($99/год) для сертификата Developer ID + нотаризации. Легальной бесплатной альтернативы нет. До тех пор:

  • .zip/.dmg остаются неподписанными — первый запуск через правый клик → Открыть или xattr -d com.apple.quarantine Wiretap.app
  • SHA256 каждого релиза позволяют проверить целостность
  • публичные логи CI дают происхождение (воспроизводимый пайплайн)

Если когда-либо настроятся APPLE_ID / APPLE_TEAM_ID / APPLE_APP_PASSWORD / MACOS_CERT_P12, заглушки ENABLE_CODESIGNING в CI — точка подключения.

Рассмотренные и отвергнутые альтернативы¶

Вариант Почему нет
Azure Trusted Signing ~$10/мес — не бесплатно; бесплатные/trial/спонсорские подписки Azure явно не поддерживаются
Microsoft Store (MSIX) Microsoft переподписывает бесплатно после сертификации — только для дистрибуции через Store; канал на будущее
Самоподписанный сертификат Обесценивает доверие SmartScreen/Gatekeeper — хуже, чем без подписи
Общие/комьюнити сертификаты Нелегально по условиям CA — никогда
