Invariantes clave

  • Ni corrutinas ni broadcasts por paquete — una cola, una tarea de vaciado, un mensaje WS batch cada ~250 ms.
  • remote_port es consciente de la dirección en todas partes; dst_port nunca se usa para clasificar (es un puerto local en tráfico entrante).
  • Ninguna llamada a terceros existe en el código sin opt-in explícito.
  • El detector protege todo estado mutable con un lock y cada contenedor está acotado en tamaño.
  • macOS: el monitoreo de media reporta supported: false; la UI oculta el badge.

Resumen por capas

  • Captura: pcap.py (ctypes hacia libpcap/Npcap) + parser.py propio (Ethernet, IPv4/IPv6 con extensiones, TCP/UDP, respuestas DNS, SNI TLS).
  • Pipeline: cola acotada → tarea de vaciado única (~4 Hz) → un mensaje WS batch por tick.
  • Clasificación: siempre sobre remote_port (consciente de dirección).
  • Enriquecimiento: DNS/SNI observados > DNS inverso > .mmdb local; tareas deduplicadas, fallos nunca cacheados para siempre.
  • Seguridad: firewall.py orquesta el firewall del SO (netsh/iptables/ pf) con reglas persistidas, lockdown y contadores de bloqueo; threatintel.py hace lookups de reputación opt-in con caché LRU.
  • Persistencia: agregados de tráfico, alertas y ajustes en SQLite; flush al apagar; retención configurable.
