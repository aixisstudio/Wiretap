Invariantes-chave

  • Sem corrotinas ou broadcasts por pacote — uma fila, uma tarefa de drenagem, uma mensagem WS batch a cada ~250 ms.
  • remote_port é consciente da direção em todo lugar; dst_port nunca é usado para classificar (é uma porta local no tráfego de entrada).
  • Nenhuma chamada a terceiros existe no código sem opt-in explícito.
  • O detector segura um lock em todo estado mutável e cada contêiner tem tamanho limitado.
  • macOS: o monitoramento de mídia reporta supported: false; a UI oculta o selo.

Camadas em resumo

  • Captura: pcap.py (ctypes → libpcap/Npcap) + parser.py próprio (Ethernet, IPv4/IPv6 com extensões, TCP/UDP, respostas DNS, SNI TLS).
  • Pipeline: fila limitada → tarefa de drenagem única (~4 Hz) → uma mensagem WS batch por tick.
  • Classificação: sempre sobre remote_port (consciente da direção).
  • Enriquecimento: DNS/SNI observados > DNS reverso > .mmdb local; tarefas deduplicadas, falhas nunca cacheadas para sempre.
  • Segurança: firewall.py orquestra o firewall do SO (netsh/iptables/pf) com regras persistidas, lockdown e contadores de bloqueio; threatintel.py faz consultas de reputação opt-in com cache LRU.
  • Persistência: agregados de tráfego, alertas e configurações em SQLite; flush ao parar; retenção configurável.
